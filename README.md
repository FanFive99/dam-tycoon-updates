# Dam Tycoon - update channel

Copies of **Dam Tycoon** (the downloaded game and the Android app) read `update.json` from this repository to see
whether a newer version is out. If so they download `dam-tycoon.html` - the whole game in one HTML file - check it
against the SHA-256 in `update.json` and install it the next time the game starts. Players can switch this off in
the game: Settings > Updates.

**Current version:** 1.1 (update 2, 2026-10-31)

**Get the game:** https://fanfive99.itch.io/dam-tycoon-idle

Published with the game's own publisher; every update replaces this repository's single commit.
